🚗 Car Theme Studio

1. Setup

Java and two free tools (apktool, uber-apk-signer) are needed. Both buttons are one-time.

2. Load a template theme APK

Drop an existing variety theme APK (for example SFP_T100_DN.apk). Its images and layouts become your starting point.

Drop .apk here or click to choose

3. Theme identity

Use a new ID name so your theme installs next to the original instead of replacing it. Keep the OEM ID unchanged.

4. Layout designer and preview

See how the home screen will look. Move and resize anything, add or remove app slots, change icon and label sizes, and make panels transparent. Click Save design before building.

5. Images

Click an image to replace it. Use the same file type and ideally the same size (shown on hover).

6. Layout files (JSON, advanced)

Positions, sizes and which widgets appear. Folders match screen sizes (layout-1600x720, layout-1280x480 and so on).

7. Build

Builds and signs the APK into the output folder. Copy it to a USB stick and install it on the head unit, or use ADB.
